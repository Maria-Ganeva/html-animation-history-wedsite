# History of Animation — Educational Website

A hand-coded, responsive educational website designed to showcase the historical development and evolution of animation technology.

## Overview
Built from scratch using semantic HTML5 and a single custom external CSS stylesheet, this site delivers a structured multi-page layout designed with web standards, clean visual hierarchy, and cross-browser responsiveness.

## Key Features & Site Architecture
* **Multi-Page Layout:** Features three primary content pages detailing key eras in animation history, supported by a dedicated custom `404.html` error page.
* **Semantic HTML5:** Built using standard semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) for accessibility and structured DOM hierarchy.
* **Custom Styling:** Styled using a single external CSS stylesheet (`webstyle.css`) incorporating responsive grid/flexbox layouts, custom typography, and hover interactions.
* **Zero External Frameworks:** Pure hand-coded HTML and CSS without relying on heavy frontend frameworks or template libraries.

## Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (`webstyle.css`)
* **Development Tools:** Visual Studio Code, Live Server extension, Git
